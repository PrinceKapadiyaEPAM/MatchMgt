## 🎯 Common Tasks Cheat Sheet

### Task 1: Add/Edit Letterhead (5 minutes)
1. Admin → Company Profile
2. Click "+ Template" button
3. Edit text in editor
4. Click Save
5. Verify on print page

→ See: [QUICK_REFERENCE.md](QUICK_REFERENCE.md) - Quick Start section

### Task 2: Customize Colors (3 minutes)
1. Select text in editor
2. Click color button
3. Choose new color
4. Save

→ See: [LETTERHEAD_EDITOR_GUIDE.md](LETTERHEAD_EDITOR_GUIDE.md) - Customization section

### Task 3: Use Different Template (2 minutes)
1. Clear editor (Select All → Delete)
2. Go to [LETTERHEAD_EXAMPLES.md](LETTERHEAD_EXAMPLES.md)
3. Copy HTML from example
4. Paste into editor
5. Customize
6. Save

→ See: [LETTERHEAD_EXAMPLES.md](LETTERHEAD_EXAMPLES.md)

### Task 4: Troubleshoot Issues (varies)
→ See: [QUICK_REFERENCE.md](QUICK_REFERENCE.md) - Quick Troubleshooting section
