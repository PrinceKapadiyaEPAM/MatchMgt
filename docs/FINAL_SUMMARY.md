## 🔧 How It Works

```
User edits in editor
        ↓
Quill generates HTML
        ↓
Click Save button
        ↓
HTML sent to server
        ↓
Saved to database (CompanyProfile.LetterheadHtml)
        ↓
On print page, HTML retrieved
        ↓
Header rendered at top of print
```
