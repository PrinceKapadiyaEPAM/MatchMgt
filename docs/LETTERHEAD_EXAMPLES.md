## Tips for Customizing Examples

1. **Change Colors**: Replace color codes
   - `#c0544b` → Your brand red
   - `#004b87` → Your brand blue
   - `#d9534f` → Bootstrap danger color

2. **Update Text**: Find and replace
   - "Company Name" → Your company name
   - "Your Tagline" → Your tagline
   - Phone numbers, emails, addresses

3. **Change Logo Path**: 
   - From: `src="/assets/Images/logo.png"`
   - To: Your actual logo path or upload new image

4. **Adjust Sizing**:
   - Font sizes: Change `font-size: 28px;`
   - Image height: Change `max-height: 80px;`
   - Padding/Margins: Change `padding: 15px;`

5. **Copy-Paste Method**:
   - Clear existing content in editor
   - Paste entire example
   - Edit text directly in the editor
   - Use toolbar to make formatting changes
   - Click Save

## Using the Quill Editor to Modify

After inserting any template:

5. Right-click for context menu

## HTML Reference Quick Tips

### Colors
- Use hex codes: `#FFFFFF`, `#000000`
- Use color names: `red`, `blue`, `green`
- Use rgba for transparency: `rgba(0,0,0,0.5)`

### Sizing
- Pixels: `10px`, `20px`, `100px`
- Percentages: `50%`, `100%` (for responsive)
- Line-height: `1.5`, `1.6` (for spacing)

### Common Styles
- **Bold**: `<strong>` or `font-weight: bold;`
- **Italic**: `<em>` or `font-style: italic;`
- **Color**: `color: #333;`
- **Spacing**: `margin: 10px;` or `padding: 15px;`
- **Border**: `border: 1px solid #ccc;`
- **Align**: `text-align: center;`, `left;`, `right;`

### Tables for Layout
```html
<table style="width: 100%;">
    <tr>
        <td style="width: 50%;">Column 1</td>
        <td style="width: 50%;">Column 2</td>
    </tr>
</table>
```

## Save & Preview

1. After editing, click **Save**
2. Go to any Print view (Program, Design, etc.)
3. Click **Print** or **Download PDF**
4. Your letterhead appears at the top

## Notes

- All examples use inline styles for maximum compatibility
- Unicode characters (॥, ॐ, etc.) are fully supported
- Images must be from accessible URLs
- Keep designs simple for better print quality
- Test print before finalizing
