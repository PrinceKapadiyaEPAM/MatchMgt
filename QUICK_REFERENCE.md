# Letterhead Editor - Quick Reference Card

## 🚀 Quick Start (2 Minutes)

1. **Go to**: Admin → Company Profile
2. **Click**: + Template button
3. **Edit**: Company name, phone, address in the editor
4. **Click**: Save
5. **Verify**: Go to Program/Design → Print → See header at top

## ✏️ Editing Tips

### Editing Text
- **Double-click** on text to edit
- **Triple-click** to select entire line
- **Highlight** text to format
- **Delete** to remove content

### Formatting
- Select text → Click toolbar button
- Example: Select "Company Name" → Click Bold
- Use color picker for any color
- Undo (Ctrl+Z) / Redo (Ctrl+Y) available

### Inserting Elements
- **Image**: Click image icon → Upload or paste URL
- **Link**: Select text → Click link icon → Enter URL
- **Table**: Use Insert Table (if available)

### Pro Tips
- Use Tab key to move between cells
- Ctrl+A to select all
- Right-click for context menu
- Drag to reorder text/images

## 🆘 Quick Troubleshooting

| Issue | Solution |
|-------|----------|
| Changes not appearing | Click Save button |
| Header not on print | Go to Company Profile, verify content exists |
| Text not visible | Check text color vs background color |
| Image not showing | Verify image URL is correct and accessible |
| Formatting lost | Use Quill's toolbar consistently |
| Can't find Company Profile | Check you're logged in as Admin |
| Editor won't open | Clear browser cache, try different browser |
